# Mahjong5

5 枚の萬子で、ツモと打牌を繰り返す一人用ブラウザーゲームです。短い局を重ねながら、麻雀の基本となる組み合わせに自然と親しめます。

[ブラウザーで遊ぶ](https://akiplaylab.github.io/mahjong5/)

## 設計原則

牌を選ぶだけで遊べるようにし、判断に必要な情報を一画面に収めます。完成時は音と光、牌の動きで手応えを返します。流局にペナルティはなく、局が終わったらすぐに次の局を始められます。

## ゲームルール

- 一萬から九萬を各 4 枚、計 36 枚使用します。
- 山をシャッフルし、4 枚を配ったあとに 1 枚ツモります。右端の少し離れた牌がツモ牌です。
- 牌をタップまたはクリックして 1 枚捨てると、次の牌を自動でツモります。
- 順子（連続した 3 枚）または刻子（同じ 3 枚）と、雀頭（同じ 2 枚）が揃うと自動で和了します。局の途中でできた組み合わせの牌も捨てられます。
- 最後のツモでも和了できます。最後のツモで和了しなかった場合は、そのあとの打牌で流局します。
- 局の終了後は「もう一度」で新しい局を始められます。累計和了回数と音の設定はブラウザーに保存します。

## 起動・検証

Node.js 22.14 以上を使用します。

```sh
npm install
npm run dev
```

ターミナルに表示された URL をブラウザーで開いてください。ブラウザーの自動再生制限により、効果音は最初の操作から有効になります。

```sh
npm test
npm run build
npm run preview
```

`npm test` は山の構成、配牌・打牌・ツモ、和了判定、流局を検証します。`npm run build` で型を確認し、静的ファイルを `dist/` に出力します。`npm run preview` でビルド結果をローカル確認できます。

## GitHub Pages への公開

GitHub Actions は [本番](https://akiplaylab.github.io/mahjong5/) に `main` を公開し、同じリポジトリから `main` へのオープン PR を `/mahjong5/test/pr-<PR 番号>/` に公開します。main への push と PR の作成・更新・再オープン・クローズ時に本番とテスト環境一覧を更新します。Actions の「Deploy to GitHub Pages」は `main` を選んで手動実行できます。

### 受け入れテスト

1. PR の作成・更新後に、Actions の「Deploy to GitHub Pages」で公開結果を確認します。ビルドに失敗した PR は一覧から外れます。
2. iPhone・iPad・PC のブラウザーで [テスト環境一覧](https://akiplaylab.github.io/mahjong5/test/) から対象 PR を開き、画面の `TEST · PR #番号 · 短縮 SHA` が確認対象のコミットと一致することを確認します。
3. 対象の変更を試し、必要に応じて牌の表示、打牌、音の設定を確認します。累計和了回数と音の設定は本番と各 PR で別々に保存されます。
4. 受け入れ後に GitHub で PR を手動マージし、本番に反映されたことと、対象 PR がテスト環境一覧から消えたことを確認します。

ローカルで PR ビルドを試す場合は、以下のように実行し、`/mahjong5/test/pr-5/` を開きます。

```sh
VITE_TEST_PR=5 VITE_TEST_SHA=0123456789abcdef npm run build:test
VITE_TEST_PR=5 npm run preview -- --mode pages-test
```
