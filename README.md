# Mahjong5

5 枚の萬子で、ツモと打牌を繰り返す一人用ブラウザーゲームです。短い局を重ねながら、麻雀の基本となる組み合わせに自然と親しめます。

[ブラウザーで遊ぶ](https://akiplaylab.github.io/mahjong5/)

## 設計原則

牌を選ぶだけで遊べるようにし、判断に必要な情報を一画面に収めます。完成時は音と光、牌の動きで手応えを返します。流局にペナルティはなく、局が終わったらすぐに次の局を始められます。

## ゲームルール

- 一萬から九萬を各 4 枚、計 36 枚使用します。
- 山をシャッフルし、4 枚を配ったあとに 1 枚ツモります。右端の少し離れた牌がツモ牌です。
- 牌をタップまたはクリックして 1 枚捨てると、次の牌を自動でツモります。
- 順子（連続した 3 枚）または刻子（同じ 3 枚）と、雀頭（同じ 2 枚）が揃うと自動で和了します。局の途中でできた組み合わせの牌も捨てられます。
- 最後のツモでも和了できます。最後のツモで和了しなかった場合は、そのあとの打牌で流局します。
- 局の終了後は「もう一度」で新しい局を始められます。累計和了回数と音の設定はブラウザーに保存します。

## 牌画像の出典

萬子 1〜9 の画像（シンプル L サイズ、66 × 90 px）は、[麻雀豆腐の麻雀画像素材](https://majandofu.com/mahjong-images)を使用しています。配布元は個人・商用での利用と画像の加工を許可しており、画像の著作権は配布元に帰属します。

## 起動・検証

Node.js 22.14 以上を使用します。

```sh
npm install
npm run dev
```

ターミナルに表示された URL をブラウザーで開いてください。ブラウザーの自動再生制限により、効果音は最初の操作から有効になります。

```sh
npm test
npm run build
npm run preview
```

`npm test` は山の構成、配牌・打牌・ツモ、和了判定、流局を検証します。`npm run build` で型を確認し、静的ファイルを `dist/` に出力します。`npm run preview` でビルド結果をローカル確認できます。

## GitHub Pages への公開

GitHub Actions は main の更新時にテストとビルドを実行し、成功すると dist/ を GitHub Pages に公開します。本番ビルドとローカルプレビューのパスは /mahjong5/ です。
